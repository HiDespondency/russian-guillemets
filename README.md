# Russian Guillemets

Локальный плагин Obsidian для замены прямых кавычек на русские ёлочки в Markdown-тексте.

## Статус

Рабочий локальный плагин. Вынесен в отдельный репозиторий для сохранения и дальнейшей доработки отдельно от общего Obsidian Vault.

## Установка

Папка плагина должна находиться в:

```text
.obsidian/plugins/russian-guillemets
```

В текущем хранилище Obsidian эта папка подключена через junction-ссылку на отдельный репозиторий:

```text
S:/Users/HiDespondency/Documents/Obsidian Plugins/russian-guillemets
```

## Состав

- `manifest.json` - описание плагина для Obsidian.
- `main.js` - рабочий код плагина.
